Lecture notes pipeline with Claude

Python · faster-whisper · Claude Code · ffmpeg · systemd

Turns four-hour class recordings into structured Obsidian notes with no manual steps: local transcription on the CPU, notes written by Claude Code in headless mode, a page per new concept and a course index.

  • Fits in 8 GB of RAM: silence-aligned ten-minute chunks cut peak audio memory from more than 6 GB to about 0.7 GB on a two-hour recording.

Retail delivery diagnostics: an end-to-end case

Python · pandas · SQL · Star schema · Chart.js · Statistics

Diagnosis of a department-store delivery network, from 62,420 raw shipment records to an executive dashboard. The monthly report said 95.7% of deliveries were on time and in full, yet management felt deliveries were getting slower. The analysis shows where and why.

  • Cleaning with lineage: 62,420 raw records reduced to 59,615 shipments, with every exclusion logged.
  • Stores compared with their own zone through Wilson intervals, so only 1 of 61 stores is flagged as significantly worse.

Milky Way structure: Gaia DR3 × APOGEE-2 DR17

Python · pandas · astropy · scikit-learn · TOPCAT

Spatial and kinematic characterisation of the Milky Way's stellar populations, built by cross-matching Gaia DR3 astrometry with APOGEE-2 DR17 spectroscopy.

  • 682,284 sources reduced to 281,612 stars through documented cuts on signal-to-noise, astrometric fit, radial-velocity scatter and parallax.
  • Velocity ellipsoid tilted by a vertex deviation of about −26.6°, consistent with asymmetric drift.

Repository · Report (PDF)

Galaxy morphology with convolutional networks

Python · TensorFlow / Keras · scikit-learn · Transfer learning

Binary classification of 5,608 MaNGA galaxy images into early types and late types, from a baseline CNN to transfer learning, with the class imbalance handled explicitly.

  • Baseline CNN: 81.0% test accuracy, held back by a recall of only 0.68 on late types.
  • A deeper CNN reached 86.3% test accuracy and raised late-type recall to 0.77.
